# CHEMY I Units 9, 11, and 12 Practice

Interactive review for CHEMY I (General Chemistry I), Units 9, 11, and 12: Quick Check questions, Explain It written prompts with model answers, and vocabulary flashcards. All content is based on OpenStax *Chemistry 2e*.

This is a single static page (`index.html`) served with GitHub Pages. To update it, replace `index.html` and commit.
